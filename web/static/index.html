    METHOD & INTERPRETATION
    A comparison you can inspect.
    RadPareto checks record compatibility before comparing minimized costs. The web view calls the same Python functions used by the command-line tool; it does not use a separate visual approximation.
    Read the software documentation ↗
    1
    Start from attributed numbers
    Source: Ma et al., Electronics 15(22), 5390, Tables 9–10, CC BY 4.0. This is analysis of published summaries; individual implementation runs and source HDL were not obtained.
    2
    Keep the transformation explicit
    The minimized timing cost is 1000 divided by mean maximum frequency. Reciprocal endpoints are reversed. This is not the mean of individual periods or measured critical-path delay.
    3
    Read conclusions within their scope
    Observed three-run ranges are not confidence intervals or guarantees about future runs. Cost dominance does not establish radiation protection, mission reliability, or a recommendation to replace a hardened design with a baseline.

# Reproducing release 0.3.0

Use a checkout of the release tag or its pinned commit. Python 3.11 or later
is required; the scientific engine and published-number analysis use only
the standard library. Run commands from the repository root. Use a new
output directory for each replay: the analysis scripts refuse an existing
directory instead of replacing results.

```sh
python -m pip install .
python -m unittest discover -s tests -v
python scripts/evaluate_contract.py
python scripts/verify_retained_artifacts.py
python benchmarks/published_case/analyze_case.py --engine-src src --out case-replay
python benchmarks/published_case/decision_atlas/analyze.py --engine-src src --out atlas-replay
python benchmarks/published_case/decision_atlas/verify_outputs.py --case-dir benchmarks/published_case --results atlas-replay --out atlas-check.json
```

The current unit/regression suite contains 79 test methods; the separate
contract script evaluates 58 specified checks. The CI engine matrix runs
these commands on Python 3.11 and 3.12 on Ubuntu and Windows. A workflow
definition alone is not evidence that a particular remote run passed;
inspect the run associated with the release commit.

## Inputs and derived outputs

`benchmarks/published_case/source_tables.csv` and `source_exact.json`
retain 78 numerical entries from Tables 9 and 10 of Ma et al., *Electronics*
2026, 15(22), 5390, DOI
[10.3390/electronics15225390](https://doi.org/10.3390/electronics15225390).
`decision_atlas/merged_context.csv` adds six Table 11 domain frequencies.
The numerical transcriptions retain CC BY 4.0 attribution; the analysis code
is MIT. Table locators, the domain mapping and source URLs accompany the
inputs. They are published resource/timing summaries, not individual raw
runs or a new hardware experiment. Full source text is not redistributed.

The parent `source_freeze.json` and atlas `source_manifest.json` bind the
transcriptions, source metadata and declared analysis plan. Each analyzer
verifies input hashes before calculation. Each output directory has a
`run_manifest.json` recording the command, Python version, analyzer hash,
engine module hashes and generated result hashes. The manifest excludes
itself from its output hash list. The separate checker records its own hash,
source-manifest hash and the analyzed result hashes.

Retained 0.3.0 results are in:

- `benchmarks/published_case/results/`: 72 budget decisions, cost records,
  candidate scopes and conditional stability boundaries.
- `benchmarks/published_case/decision_atlas/results/`: the exact-reference
  atlas, numerical margins, frequency-breakpoint conversion diagnostics, endpoint-only
  precision sensitivity and separate implementation-context comparisons.
- `benchmarks/published_case/decision_atlas/independent_check.json`: the
  independent Decimal check of those retained atlas results.

The retained result directories were generated by the same commands using
these public relative paths as `--out`. Replays should use the fresh paths
above. To check the retained atlas directly without regenerating it:

```sh
python benchmarks/published_case/decision_atlas/verify_outputs.py --case-dir benchmarks/published_case --results benchmarks/published_case/decision_atlas/results --out retained-atlas-check.json
```

Compare numerical files rather than requiring a byte-identical run manifest
across Python versions, commands or operating systems. Do not edit a saved
manifest to conceal such differences. A hash establishes which bytes were
used, not source authenticity, scientific correctness or measurement validity.

## Expected finite checks and limits

The atlas has 532 exact-reference regions and 3,192 tested design/region
representatives. All checked engine labels agree with the direct-frequency
reference. Two equality decisions differ from the former mixed conversion
paths; the original 72 scenario labels are unchanged. The separate Decimal
checker verifies the complete unique representative product, six metric
rows, all 15 context pair orders and completeness of the 24 changed
precision rows across 516 reference checks.

The partition is exhaustive for the exact printed-decimal reference problem.
Finite representative checks do not prove binary64 engine behavior at every
arbitrarily close decimal input. Reporting-precision sensitivity assumes
nearest-0.001-MHz endpoint rounding, encloses endpoints by +/-0.0005 MHz and
holds means fixed. It supplies no confidence level or future-run guarantee.
The context diagnostic compares standalone three-run means with merged
worst-case summaries; two reversed pair orders are descriptive, not causal.
See [validation scope](validation.md) and the
[atlas methods](../benchmarks/published_case/decision_atlas/README.md).

## Replaying retained historical experiments

The following methods retain the stated historical study versions and
denominators. Fresh runs with 0.3.0 are current software replays, not new
hardware observations or replacements for the retained timing measurements.
The reference implementation needs its separately pinned dependencies.

```sh
python -m pip install -r benchmarks/contracts/requirements-reference.txt
python scripts/run_contract_study.py --cases benchmarks/contracts/cases.json --baseline benchmarks/contracts/tabular_reference.py --engine-root . --output contract-replay
python scripts/evaluate_properties.py --cases benchmarks/properties/cases.json --engine-root . --output property-replay
python scripts/evaluate_certificates.py --oracle benchmarks/certificates --engine-root . --output certificate-replay
python benchmarks/mutation/replay.py --output mutation-replay
```

The mutation command copies and executes the frozen 0.2.0a1 baseline and
variants. It does not mutate the installed 0.3.0 package. Eleven of the twelve
specified mutants were detected by the frozen diagnostic families; the
surviving tie-handling mutant remains in the denominator. See the
[mutation protocol](../benchmarks/mutation/README.md).

Generic synthesis/fault-free checks need an additional Yosys environment;
follow [original HDL](open_benchmarks.md) and
[external HDL](external_benchmarks.md). These structural tests do not estimate
flash-device timing, radiation protection or mission reliability.

The public package provides the permitted scientific inputs, numerical
methods, tests and outputs. Manuscript sources, publication artwork, full
literature copies, private reviews and credentials do not belong here.
